# Plugin de UltiMaker Cura — Slice2Price

Este plugin transmite automáticamente los datos de tiempo de impresión y peso de material calculados en **UltiMaker Cura** hacia **Slice2Price**.

## Instalación

1. En Windows, abre tu carpeta de plugins de Cura:
   ```
   %APPDATA%\cura\<versión>\plugins
   ```
   *(Ejemplo: `C:\Users\TuUsuario\AppData\Roaming\cura\5.6\plugins`)*

2. Copia la carpeta `cura/` dentro de esa ruta y renómbrala como `Slice2Price`.
3. Reinicia UltiMaker Cura.
4. Al hacer clic en **Laminar (Slice)** en Cura, los datos se enviarán y Slice2Price los detectará de inmediato en segundo plano.
